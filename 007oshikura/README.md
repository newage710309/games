# さくらちゃんの おしくらまんじゅう 🐣

冬の森の動物たちが、2 匹 1 組で落ちてくる落ちものパズル。同じなかまを 4 匹くっつけると
「ぎゅっ」とおしくらまんじゅうになって消える。続けて消えるとれんさで高得点。
降ってくるおじゃまの雪だるまは、となりで動物が消えると溶ける。3 面までクリアすると、森に春がくる。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている（動物の絵は案内係（005）と同じ）。

## 遊び方

| 操作 | PC | スマホ・タブレット（画面のどこでも） |
|---|---|---|
| 左右に 1 マス | `←` `→`（`A` `D`）。押しっぱなしで続けて動く | 左右にスワイプ（約 28px ごとに 1 マス。指を動かし続けると続けて動く） |
| 回す（右回り） | `↑` / `Space` / `X` / `W` | タップ / 上にスワイプ |
| 回す（左回り） | `Z` | — |
| はやく落とす | `↓`（`S`）を押しているあいだ | 下にスワイプしているあいだ（指を止めるとふつうの速さに戻る） |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

スワイプは、指を離すのを待たずに一定の距離を動かした瞬間に反応する（`src/game/input.ts`）。

- フィールドはよこ 6 れつ × たて 12 だん。組は左から 3 れつめの上から出てくる。落ちる先は点線の枠で見える。
- 回すときは下の 1 匹が軸。かべや他のものに当たるときは横にずれて回り、左右とも狭いときは上下を入れかえる。
- 着地してから 0.5 秒は左右に動かせる（はやく落としているときは 0.12 秒）。片方の下が空いていれば、その 1 匹だけ下まで落ちる。
- 同じ動物が上下左右に 4 匹以上つながると「ぎゅっ」と消える（ななめは数えない）。消えたあと上のものが落ちて、また 4 匹そろうとれんさ。
- 雪だるまは何組か落とすごとに、ばらばらの列に降ってくる（右の欄に「ゆきだるま あと ○くみ」と予告）。雪だるまはくっついても消えない。
  となり（上下左右）で動物が消えると溶ける。3 面の **おおきい雪だるま**（赤いマフラー）は 1 回溶けるとふつうの雪だるまになり、2 回で消える。
- 決められた数の動物を消すと面クリア。**出てくる場所（左から 3 れつめのいちばん上）がふさがったらゲームオーバー**（1 回で終わり、コンティニューなし）。

| 得点 | |
|---|---|
| 動物を消す | 1 匹 10 点 × れんさの倍率（1 れんさ目 ×1、2 ×2、3 ×4、4 ×8、5 ×16、6 から ×32） |
| 2 種類以上を同時に消す | 1 種類ふえるごとに 30 点 |
| 雪だるまを溶かす | 1 回 20 点 |
| 面クリア | 500 点 |

## 面

| 面 | 動物 | クリアまで | 落ちる速さ（段/秒） | 雪だるま |
|---|---|---|---|---|
| 1 めん | シマエナガ・エゾリス・カラス・キタキツネ（4 種） | 40 匹 | 0.9 → 1.3 | 10 組ごとに 2〜3 こ |
| 2 めん | シマエナガ・ヤマガラ・エゾモモンガ・ユキウサギ・アカゲラ（5 種） | 60 匹 | 1.5 → 2.1 | 7 組ごとに 3〜4 こ |
| 3 めん | シマエナガ・ゴジュウカラ・キタキツネ・ユキウサギ・カラス（5 種） | 80 匹 | 2.2 → 3.0 | 6 組ごとに 4〜5 こ（4 割がおおきい雪だるま） |

落ちる速さは、その面で消した数に合わせて少しずつ上がる。面ごとに盤面は空になる。
1 面のあとは「みんなで おしくらまんじゅう」、2 面のあとは「おおきい ゆきだるまが きた！」の休憩デモ、
3 面のあとはエンディング（ぽかぽかで はるが きた！）。

数値は `src/game/stages.ts` にまとめてある。自動プレイ（`src/game/bot.ts`。置ける場所をぜんぶ試して、
消える数・れんさ・くっつき具合・高さで選ぶ。考える時間・操作の速さ・置きまちがいの割合を変えて各 30 回）での目安：

| ボット | 考える時間 | 操作 | まちがい | つぎの組まで考える | ぜんぶクリア | 2 面まで | 1 面まで |
|---|---|---|---|---|---|---|---|
| じょうず | 0.25 秒 | 8 回/秒 | なし | する | 28 回 | 2 回 | 0 回 |
| ふつう | 0.6 秒 | 5 回/秒 | 1 割 | しない | 7 回 | 23 回 | 0 回 |
| はじめて | 1 秒 | 3 回/秒 | 2.5 割 | しない（はやく落とさない） | 5 回 | 23 回 | 2 回 |

ボットは盤面をすみずみまで見て選ぶので、人が遊ぶより強めに出る。1 面ではどのボットも負けなかった。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173/
npm run build      # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
```

- `design.html`（開発時だけ）：場面ごとの画面と、キャラクターの一覧。
- 開発時はコンソールから `__game`（状態）、`__seededRandom`（乱数の固定）、`__render` を使える。
  自動プレイは `const { SKILLS, playOnce } = await import('/src/game/bot.ts')` を読みこんで、
  `playOnce(new (__game.constructor)({ play() {}, muted: false, toggleMute() {} }, __seededRandom(1)), SKILLS['ふつう'], __seededRandom(2))`。
  （ハイスコアが localStorage に保存されるので、測ったあとは `localStorage.removeItem('sakura-oshikura.highscore.v1')` で消す）
