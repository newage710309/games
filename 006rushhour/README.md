# さくらちゃんのぎゅうぎゅうでんしゃ 🚃

冬の森の駅で、ドアからあふれるお客さんを、駅員のさくらちゃんが電車に押しこむアクションゲーム。
昔の LSI ゲーム、バンダイ「ラッシュアワー」（1982 年）の遊び方（3 つのドアからあふれる乗客を押し屋が押しこむ）を、
シマエナガの「さくらちゃん」と冬の森の動物たちに置きかえたもの。3 本の電車をぜんぶ発車させたらクリア。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| 列へ移動 | 列のどこかをクリック / `←` `→`（`A` `D`） | 列のどこかをタップ |
| おばあちゃんを助けに行く | 左はしをクリック / `←` | 左はしをタップ |
| ゆきまるくんを乗せる | 走っているゆきまるくんをクリック | タップ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

- 電車のドアは 3 つ。お客さんはドアからあふれ出て、手前のホームの端へ向かって列になる（新しい人はドアのすぐ前に出て、列全体が手前へずれる）。ときどき 2 つの列に同時にあふれる。さくらちゃんがドアの前に立っている列（空の列）には出てこない。
- さくらちゃんは列のいちばん後ろに立って、自動で 1 人ずつ押しこむ（押しこむたびに 1 人ぶん前へ進み、列が空になったらドアの前に立つ）。
- 列に 4 人並ぶと「あぶない！」。5 人目がホームの端に着くと大きく「あぶない！！」になり、0.9 秒のうちに押しこんで 4 人に戻せばセーフ。**間に合わなければゲームオーバー**（1 回で終わり、コンティニューなし）。
- 電車ごとに発車までの時間が決まっている（上の欄に「のこり ○びょう」）。時間になるとお客さんがあふれるのが止まり、「ドアが しまるよ！」。ホームに残ったお客さんをぜんぶ押しこんだら発車（ボーナス 500 点）するので、発車のときホームにはだれも残らない。3 本とも発車させたらクリア（数え方は 1 ぽんめ・2 ほんめ・3 ぼんめ）。

| 得点 | |
|---|---|
| 押しこむ | 1 人 10 点（大荷物のお客さんは 20 点） |
| おばあちゃんを助ける | 100 点 |
| ゆきまるくんを乗せる | 200 点 |
| 発車 | 500 点 |

## 出てくるもの

- **フクロウのおばあちゃん**：ときどき左はしのベンチに来る。こちらを向いているときに横へ行くと助けられる（向こうを向いているあいだは待つ）。助けなくてもミスにはならない。
- **へんそうおばあちゃん**（2 本目から）：おばあちゃんに化けた雪だるま。助けるとゲームオーバー。にんじんの鼻と枝の腕で見分ける。向こうを向いているときは、本物と同じ後ろ姿で見分けられない。
- **大荷物のお客さん**（2 本目から）：大きなリュックを背負っていて、2 回押さないと入らない。
- **ねぼうのゆきまるくん**（2 本目から）：発車まで残り 8 秒になると、ホームを走ってくる。タップして乗せると 200 点。乗せなくてもミスにはならない。

## 電車（面）

| 電車 | 発車までの時間 | あふれる間隔（秒） | 2 列同時 | 大荷物 | へんそうおばあちゃん | ゆきまるくん |
|---|---|---|---|---|---|---|
| 1 本目 | 25 秒 | 1.08 → 0.88 | 30% | なし | なし | なし |
| 2 本目 | 30 秒 | 0.98 → 0.78 | 40% | 12% | 35% | あり |
| 3 本目 | 35 秒 | 0.89 → 0.71 | 50% | 18% | 45% | あり |

数値は `src/game/trains.ts` にまとめてある。自動プレイ（いちばん長い列へ行く。反応の速さと、列の選びまちがいの割合を変えて各 30 回）での目安：
反応 0.25 秒・まちがいなし → 30 回中 10 回クリア、0.5 秒・1 割まちがい → 8 回、1 秒・2.5 割まちがい → 5 回。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173/
npm run build      # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
```

- `design.html`（開発時だけ）：場面ごとの画面と、キャラクターの一覧。
- 開発時はコンソールから `__game`（状態）、`__seededRandom`（乱数の固定）、`__render` を使える。
