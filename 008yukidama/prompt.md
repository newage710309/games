## ゲーム仕様

雪玉に乗って坂を下り、雪玉を大きく育てて、ふもとの雪だるまのとりでに体当たりするゲーム。全 3 面。

### 画面と操作

- 上から見下ろした雪山の坂を、雪玉が画面の下へ向かって自動で転がる。雪玉は画面の上寄りに置き、進む先が見えるようにする。
- さくらちゃんは雪玉の上でちょこちょこ走る（玉乗り）。
- 雪玉が大きくなるのに合わせて、少しずつカメラを引く。
- 操作は左右だけ。

| 操作 | PC | スマホ |
|---|---|---|
| 左右に動かす | `←` `→`（`A` `D`）またはマウス | 画面のどこでも左右にドラッグ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |

### 中心になるルール

**自分より小さいものは巻きこめて、大きいものに当たると雪玉が欠ける。**

- **大きさ:** 画面に「30cm」のように表示する。大きさがライフも兼ねる。
- **育ち方:** 新雪の上を転がると少しずつ大きくなり、雪だまりを通るとぐっと増える。
- **重さ:** 大きくなるほどスピードが上がり、曲がりにくくなる。
- **ミス:** 大きいものに当たると、雪玉が 2 割欠ける。雪のかけらが飛び散る演出を入れる。
- **ゲームオーバー:** 10cm を下回ると、さくらちゃんが転げ落ちて終わり。1 回で終わりで、コンティニューはなし。
- **巻きこんだものの見た目:** 枝や雪だるまなどが雪玉に刺さったまま、一緒に回る。

### コースに出てくるもの

| もの | 巻きこめる大きさ | 当たるとどうなるか |
|---|---|---|
| 木の実 | いつでも | 得点が入る |
| 小枝・小石 | 20cm〜 | 小さいうちは欠ける |
| 雪だるま兵（左右に歩く） | 60cm〜 | 小さいうちは欠ける |
| 小さな木 | 100cm〜 | 小さいうちは欠ける |
| 大きな岩 | 巻きこめない | 必ず欠ける |
| 細い門 | 巻きこめない | 門より大きいと通れず、欠ける |
| 氷の地面 | ー | 滑りやすく、雪がつかない |
| 日なた | ー | 少しずつ溶けて小さくなる |

**分かれ道がこのゲームの悩みどころ。** 雪だまりの多い広い道には、大きな岩も多く置く。安全な近道は細い門の先に置き、大きく育ちすぎると通れないようにする。わざと日なたを通って小さくし、門を抜ける手も成り立つようにする。

### ふもとのとりで

- 面の最後に、とりでへ自動でつっこむ。大きさに応じて壊れる量が変わり、派手に崩れる見せ場にする。
- **目標に届いたとき:** 面クリア。目標ちょうどで ★、1.5 倍で ★★、2 倍で ★★★。
- **目標に届かなかったとき:** 雪玉がはじき返されてゲームオーバー。
- プレイ中は、残りの距離と目標の大きさをずっと表示する。

### 面

| 面 | 舞台 | 時間 | はじめの大きさ | 目標 | 新しく出るもの |
|---|---|---|---|---|---|
| 1 めん | ふもとの林 | 約 40 秒 | 30cm | 100cm | 小枝・小石・木の実・小さな木・岩・雪だまり |
| 2 めん | 細い谷 | 約 50 秒 | 30cm | 200cm | 雪だるま兵・細い門・分かれ道・日なた |
| 3 めん | ふぶきの山 | 約 60 秒 | 30cm | 300cm | 氷の地面・ふぶき（先が見えにくい） |

### デモ

- **1 面のあと:** 雪だるまたちが慌てて作戦会議をする。
- **2 面のあと:** 大きな雪だるまの大将が登場する。
- **エンディング:** 大将が「もうしません」と降参し、みんなで特大の雪玉を頭にのせる。雪だるま退治のはずが、史上最大の雪だるまができてしまうオチ。

### 難しさの目安

- 007 の `src/game/bot.ts` と README のように、腕前の違うボットを 30 回ずつ走らせて確かめ、結果を README に載せる。
- 「はじめて」のボットでも 1 面はたいていクリアでき、3 面の ★★★ は上手な人でも簡単には取れない、くらいを目指す。
- 広い道だけ、または近道だけを選び続けて楽に勝てないよう、分かれ道の損得を確かめる。
