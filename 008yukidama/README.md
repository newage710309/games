# さくらちゃんの雪玉ころがし ⛄

雪玉に乗って坂を下り、雪玉を大きく育てて、ふもとの雪だるまのとりでに体当たりするアクション。
自分より小さいものは巻きこめて、大きいものに当たると雪玉が欠ける。大きさがライフも兼ねている。全 3 面。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている（さくらちゃんと雪だるまの絵はおしくらまんじゅう（007）と同じ）。

## 遊び方

| 操作 | PC | スマホ・タブレット（画面のどこでも） |
|---|---|---|
| 左右に動かす | `←` `→`（`A` `D`）またはマウス | 左右にドラッグ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

マウスは、画面の左はしから右はしが道の左はしから右はしにあたる。指は動かした分だけ動く（`src/game/input.ts`）。

- 雪玉は坂を自動で下る。大きくなるほど速くなり、曲がりにくくなる。カメラも少しずつ引く。
- 新雪の上を転がると少しずつ、雪だまりを通るとぐっと大きくなる。巻きこんでも大きさは増えない（点が入り、雪玉に刺さったまま一緒に回る）。
- 大きいものに当たると 2 割欠ける。欠けた直後の 1 秒は無敵。**10cm を下回ると、さくらちゃんが転げ落ちてゲームオーバー**（1 回で終わり、コンティニューなし）。
- 足もとの輪が目印：青い点線は巻きこめる、赤い輪と「！」は当たると欠ける。大きくなると輪の色が変わる。
- 面の最後はとりでへ自動でつっこむ。目標に届いていれば面クリア（ちょうどで ★、1.5 倍で ★★、2 倍で ★★★）、届いていなければはじき返されてゲームオーバー。

| もの | 巻きこめる大きさ | 当たるとどうなるか |
|---|---|---|
| 木の実 | いつでも | 得点が入る |
| 小枝・小石 | 20cm〜 | 小さいうちは欠ける |
| 雪だるま兵（左右に歩く） | 60cm〜 | 小さいうちは欠ける |
| 小さな木 | 100cm〜 | 小さいうちは欠ける |
| 大きな岩 | 巻きこめない | 必ず欠ける |
| 細い門 | 巻きこめない | 看板より大きいと通れず、欠けてはじき返される |
| 氷の地面 | ー | 滑りやすく、少し速くなり、雪がつかない |
| 日なた | ー | 少しずつ溶けて小さくなる |

**分かれ道:** 雪だまりの多い広い道には、大きな岩も多い。門の先の近道は岩がなく、1.25 倍の速さで下れるが、雪だまりは小さなものが 2 つだけ。
門より大きいときは、門の手前の日なたをわざと通って小さくすれば抜けられる。

| 得点 | |
|---|---|
| 木の実 | 20 点 |
| 巻きこみ | 小枝・小石 10 点、雪だるま兵 30 点、小さな木 50 点 |
| とりでに着いたときの大きさ | 1cm につき 10 点 |
| 面クリア | 500 点 |
| 一度も欠けずにクリア | 1000 点 |

## 面

| 面 | 舞台 | 時間 | はじめの大きさ | 目標 | 新しく出るもの | 門の大きさ |
|---|---|---|---|---|---|---|
| 1 めん | ふもとの林 | 約 40 秒 | 30cm | 100cm | 小枝・小石・木の実・小さな木・岩・雪だまり | ー |
| 2 めん | ほそい谷 | 約 50 秒 | 30cm | 200cm | 雪だるま兵・細い門・分かれ道・日なた | 90・140・190cm |
| 3 めん | ふぶきの山 | 約 60 秒 | 30cm | 300cm | 氷の地面・ふぶき（先が見えにくい） | 110・180・250cm |

コースの並びは面ごとに決まっていて、ものの配置は遊ぶたびに変わる（`src/game/course.ts`）。
1 面のあとは「ゆきだるまたちの さくせんかいぎ」、2 面のあとは「たいしょうが あらわれた！」の休憩デモ、
3 面のあとはエンディング（大将が「もうしません」と降参し、特大の雪玉を頭にのせて、史上最大の雪だるまができてしまう）。

数値は `src/game/stages.ts` にまとめてある。自動プレイ（`src/game/bot.ts`。行き先の候補を 13 か所試し、
見えているものを通ったときの大きさの増減で選ぶ。考えなおす間隔・見える距離・ものに気づく割合・ぶれ・慎重さを変えて各 30 回）での目安：

| ボット | 考えなおす間隔 | 見える距離 | 気づく割合 | ぜんぶクリア | 2 面まで | 1 面まで | 0 面 | 1 面の星（★/★★/★★★） | 3 面の星（★/★★/★★★） |
|---|---|---|---|---|---|---|---|---|---|
| じょうず | 0.12 秒 | 640 | ぜんぶ | 20 回 | 9 回 | 1 回 | 0 回 | 0 / 20 / 10 | 20 / 0 / 0 |
| ふつう | 0.28 秒 | 440 | 85% | 21 回 | 6 回 | 3 回 | 0 回 | 9 / 16 / 5 | 21 / 0 / 0 |
| はじめて | 0.5 秒 | 300 | 65% | 4 回 | 9 回 | 14 回 | 3 回 | 13 / 14 / 0 | 4 / 0 / 0 |

- 「はじめて」でも 1 面は 30 回中 27 回クリア。
- 3 面の ★★★（600cm）はどのボットも 0 回。3 面で岩に当たる回数は「じょうず」で平均 10 回。
  当たる回数の上限を決めて「じょうず」を走らせると、4 回までなら平均 752cm、0 回なら平均 1028cm に届くので、★★★ は岩を半分以下によけ続ければ届く見こみ（人が取れるかは未確認）。
- 「じょうず」と「ふつう」の差は小さい。ボットは先の岩を見ていても雪だまりを優先しがちで、「名人」（長い距離を見て、岩をとてもいやがる設定）はかえって育ちきらず 8 回しかクリアできなかった。腕前の差より、岩と雪だまりの見切りが結果を分ける。

分かれ道の損得（腕前は「じょうず」と同じ、各 30 回）：

| 道の選び方 | ぜんぶクリア | 2 面で着いた大きさ（平均） | 2 面で欠けた回数（平均） | 2 面クリア |
|---|---|---|---|---|
| 広い道だけ | 22 回 | 268cm | 5.5 回 | 29 回 |
| 使い分け（最後だけ広い道、ほかは通れれば近道） | 19 回 | 215cm | 2.6 回 | 20 回 |
| 通れれば近道 | 9 回 | 191cm | 0.7 回 | 9 回 |
| 近道だけ（大きければ日なたでとかす） | 3 回 | 187cm | 0.8 回 | 7 回 |

近道だけでは 2 面の目標にわずかに届かない。広い道だけなら育つが、毎回 5 回以上欠ける（ノーミスの 1000 点はまず取れない）。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173/
npm run build      # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
```

- `design.html`（開発時だけ）：場面ごとの画面と、雪玉・障害物・とりで・背景の一覧。
- 開発時はコンソールから `__game`（状態）、`__seededRandom`（乱数の固定）、`__render` を使える。
  自動プレイは `const { SKILLS, playOnce } = await import('/src/game/bot.ts')` を読みこんで、
  `playOnce(new (__game.constructor)({ play() {}, muted: false, toggleMute() {} }, __seededRandom(1)), SKILLS['ふつう'], __seededRandom(2))`。
  （ハイスコアが localStorage に保存されるので、測ったあとは `localStorage.removeItem('sakura-yukidama.highscore.v1')` で消す）
