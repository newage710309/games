# さくらちゃんのシャッターチャンス 🌸

森の新聞「もりのしんぶん」のカメラマンになって、動き回るさくらちゃんを撮影するゲーム。
フィルムは 1 面 10 枚。編集長のフクロウが出すお題に合う写真を撮ろう。全 3 面。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている（さくらちゃん・雪だるま・鳥はエナガだんご（010）の絵、
編集長のフクロウはつまみ食い（004）のフクロウ先生の絵に、ハンチング帽と赤えんぴつを描き足したもの。
めずらしいポーズ 12 種類とそっくりさんは描き足した）。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| カメラの枠を動かす | マウス / `←` `→` `↑` `↓` | 画面のどこでもドラッグ（指の動いた分だけ枠が動く） |
| シャッター | クリック / `Space` | 右下のシャッターボタンをタップ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

- スマホは、片方の親指でドラッグしながら、もう片方の親指でシャッターを押せる（マルチタッチ。指ごとに追いかける）。
- マウスでシャッターボタンをクリックしたときは、枠はボタンへ寄らない。

### 進め方

1. 面の始めに、編集長がお題を出す。
2. 森の場面が横にゆっくり流れる（1 面 50 秒）。さくらちゃんは走る・跳ねる・木の陰に入る・奥へ行く・手前に来る。
   奥へ行くと小さく、手前に来ると大きく写る。
3. シャッターを押すと、フィルムを巻く「ジー」の間（1 秒）は撮れない。
4. 場面が終わると、撮った写真を点数の高い順に並べる。編集長がいちばん点の高い写真を「もりのしんぶん」の 1 面にえらび、森じゅうに配られる。
5. お題に合った 60 点以上の写真が 1 枚もなければゲームオーバー（コンティニューなし）。

### 写真の点数（1 枚 100 点満点＋ボーナス）

撮った瞬間の場面の情報（だれがどこに、どんな向き・ポーズ・速さでいたか）と枠の位置から計算する（`src/game/photo.ts`）。画像は解析しない。

| 見るところ | 配点 | 減点されるとき |
|---|---|---|
| 写っている | 30 | 枠からはみ出ている、または手前のものに隠れている（見えている部分の割合で数える） |
| 大きさ | 20 | 遠くて小さい、近すぎる（体の高さが枠の 45〜68% で満点） |
| 構図 | 20 | 枠の中心からずれている |
| 隠れていない | 15 | 手前の枝・木・雪・雪だるま・そっくりさん・鳥に隠れている。体の上に取った点で調べる |
| ブレていない | 15 | 画面の上で速く動いている瞬間に撮った |

| ボーナス | 点数 |
|---|---|
| こちらを向いている | ＋10 |
| めずらしいポーズ | ＋20 |

- 本物のさくらちゃんが少しでも（体の 25% 以上）写っていれば、本物の写真として採点する。そっくりさんがいっしょに写っていても「ちがう子」にはしない。
  そっくりさんしか写っていない写真、だれも写っていない写真は 0 点。
- 体の 4 割以上が隠れている写真は、お題にもポーズにも数えない。
- 撮るたびに右上に小さな写真と点数を 1.6 秒出す（ゲームは止めない）。いちばん大きかった減点の理由をひとこと
  （「ちょっと ちいさい」「ぶれちゃった」「かくれてる」「ちがう子だよ」など）、80 点以上は「ベストショット！」、お題に合えば ✓、
  ポーズなら「ポーズ はっけん！」。音は 60 点未満がカシャ、80 点以上がカシャ＋キラン、ポーズ発見がファンファーレ。

| 雪に ずぼっ | 雪山をじっと見る | 3 |
| でんぐりがえり | ぐっとしゃがむ | 3 |
| 木の実を くわえる | 木の実が落ちてくる | 1・2 |
| うたう | むねをふくらませる | 2 |
| いねむり | こっくりこっくり | 1 |
| ウインク | 目がきらっ | 2・3 |

## 面

| 面 | 舞台 | お題 | 邪魔になるもの |
|---|---|---|---|
| 1 めん | 雪の森の朝 | こっちを むいた さくらちゃん | 白樺・しげみ・雪山が多く、手前に若い松や雪をのせた枝。さくらちゃんがよく物陰に入る |
| 2 めん | 鳥たちの集まる木 | 羽を ひろげた しゅんかん | 桜色のそっくりさんが 5 羽（本物は尻尾が長く、頭の飾りが花。そっくりさんは尻尾が短く、飾りが星） |
| 3 めん | 夕暮れの雪原 | なかまと だんごに なっているところ | そっくりさん 4 羽、雪だるまが手前を横切る（6 回）、雪玉で画面が白くなる（6 回） |

- お題に合う瞬間は 1 面の中で何度も来る（1 面はこちらを向いて立ち止まる、2 面は飛ぶ・羽を広げる、3 面はなかまが 3 回集まってだんごになる）。
- どの面にも小さな雪だるまがこっそりついてきていて、写真のすみに写りこむ。エンディングでは、プレイヤーが撮った写真に丸をつけて見せる。

## 得点

| 内容 | 点数 |
|---|---|
| 撮った写真 | 各写真の点数の合計 |
| お題に合った（60 点以上の）写真がある | ＋50 |
| 新しいポーズをずかんに登録 | 1 種類につき ＋30 |
| 面クリア | ＋50 |

- 面のあとの画面に「この めんの とくてん」と内訳、これまでの合計を出す。最後の結果画面は、各面の得点を足すと「ごうけい（てんすう）」になる。
- ★ は、その面の写真の点数の合計（ボーナス込み）で決める：700 点以上で ★、850 点以上で ★★、1000 点以上で ★★★。
- 最後の点数で称号が 5 段階で出る。いちばん上は、じょうずなボットでも 1 割くらいしか取れない点数にしてある。

| 称号 | 点数 |
|---|---|
| みならい カメラマン | 1,900 未満 |
| しんまい カメラマン | 1,900〜 |
| いちにんまえ カメラマン | 2,700〜 |
| ベテラン カメラマン | 3,150〜 |
| でんせつの カメラマン | 3,500〜 |

### 仕様から変えたところ

- **得点の × 10 をやめた。** 仕様は「写真の点数 × 10、お題 500、ポーズ 300、クリア 500」だったが、写真の合計（例：989）と得点（10,890）が
  別の数字に見えて分かりにくいので、写真の点数をそのまま足し、ボーナスも 1/10 にした（比率は同じ）。
- **★ の基準を上げた。** 仕様の 600／750／900 では、ふつうのボットでも 3 面すべて ★★★ が取れてしまったので、700／850／1000 にした。
- **雪をかぶったさくらちゃん（1 面）はなくした。** 遊んでみて意味が薄かったので、かわりに 1 面の障害物を増やした。
- **そっくりさんは 2 面だけでなく 3 面にも出る。** 数も増やした（2 面 5 羽、3 面 4 羽）。
- **「写っている」は隠れた部分も引く。** はじめは枠に入っている割合だけで数えていたが、手前の松にほとんど隠れた写真が 100 点を超えたので変えた。

## ボットでの確認結果

`npm run bot` で、腕前の違うボットを 30 回ずつ走らせた結果（`src/game/bot.ts`）。ボットは、少し前に見えた位置へ枠を動かし、
「撮ればこの点になりそう」と思ったら反応の遅れのあとでシャッターを押す。お題の写真がまだなければ、お題に合う瞬間を優先する。

| ボット | 枠を動かす速さ | 反応の遅れ | そっくりさんを見分けそこねる割合 | ねらいのぶれ |
|---|---|---|---|---|
| はじめて | 260 px/秒 | 0.5 秒 | 35% | ±22 px |
| ふつう | 420 px/秒 | 0.32 秒 | 15% | ±13 px |
| じょうず | 700 px/秒 | 0.2 秒 | 4% | ±8 px |

| ボット | 面 | とどいた | クリア | ★ 以上 | ★★ 以上 | ★★★ | 写真の合計（平均） | 1 枚の平均 |
|---|---|---|---|---|---|---|---|---|
| はじめて | 1 めん | 30 | 100% | 100% | 73% | 3% | 867 | 87 |
| はじめて | 2 めん | 30 | 70% | 37% | 0% | 0% | 603 | 64 |
| はじめて | 3 めん | 21 | 90% | 48% | 10% | 0% | 655 | 68 |
| ふつう | 1 めん | 30 | 100% | 100% | 90% | 7% | 935 | 93 |
| ふつう | 2 めん | 30 | 83% | 70% | 50% | 3% | 814 | 82 |
| ふつう | 3 めん | 25 | 100% | 92% | 68% | 8% | 861 | 86 |
| じょうず | 1 めん | 30 | 100% | 100% | 100% | 37% | 987 | 99 |
| じょうず | 2 めん | 30 | 90% | 90% | 80% | 27% | 925 | 93 |
| じょうず | 3 めん | 27 | 100% | 100% | 93% | 11% | 953 | 95 |

| ボット | エンディングまで | 平均点 | 称号（みならい・しんまい・いちにんまえ・ベテラン・でんせつ） |
|---|---|---|---|
| はじめて | 63% | 2,264 | 8・15・7・0・0 |
| ふつう | 83% | 2,854 | 1・6・14・9・0 |
| じょうず | 90% | 3,192 | 1・2・2・24・1 |

- 「はじめて」のボットでも 1 面は必ずクリアできる。いちばんつまずくのは、そっくりさんの多い 2 面。
- 3 面の ★★★ は、じょうずなボットでも 11%。
- 「とりあえず連打」と「いい瞬間を待つ」の比べ（腕前は ふつう）：

| ボット | 1 めんの 1 枚の平均 | 2 めんの クリア | エンディングまで | 平均点 |
|---|---|---|---|---|
| ふつう（待つ） | 93 | 83% | 83% | 2,854 |
| ふつう（連打） | 74 | 50% | 20% | 1,860 |

- `npm run check-score` で、ボット 120 回・写真 3,000 枚あまりについて、写真の点数が内訳と一致すること、面の得点・★・合計が上の表どおりに計算されていることを確かめている。
- ブラウザでも、全 3 面からエンディング・結果画面まで通しで動かした。スマホ幅（375×812）で横にはみ出さないこと、
  ドラッグ中に別の指でシャッターを押せること、「❚❚」でポーズできることを確かめた。

## 開発

```bash
npm install
npm run dev          # http://localhost:5173/
npm run build        # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
npm run bot          # 腕前の違うボットを 30 回ずつ走らせて、上の表を出す（回数を変えるとき：npm run bot -- 50）
npm run check-score  # 得点の内訳と合計を確かめる
```

- `design.html`（開発時だけ）：場面ごとの画面と、さくらちゃんの動き・ポーズ 12 種・そっくりさん・編集長・雪だるま・枠と採点・新聞・背景の一覧。
- 開発時はコンソールから `__game`（状態）、`__render`、`__Bot`・`__SKILLS`（ボット）を使える。
- 数値は `src/game/stages.ts`、写真の採点は `src/game/photo.ts`、場面の動きは `src/game/field.ts` にまとめてある。
- ハイスコア・ポーズずかん・アルバムは localStorage に保存される（`sakura-shutter.highscore.v2`、`sakura-shutter.zukan.v1`、`sakura-shutter.album.v1`）。
  アルバムは写真の画像ではなく撮った瞬間の場面の情報を残し、表示するときに描き直す（新しいものから 48 枚）。
- `promo/shutter_promo.mp4`：宣伝動画（縦 1080×1920・約 13 秒・効果音つき）。

## 公開

このリポジトリは**ソース管理用**。公開は会社サイトへ手動で配置する。

1. `npm run build`
2. `dist/` の中身を会社サイトの `files/games/011shutter/` にコピー
3. 会社サイト側でコミットして push
