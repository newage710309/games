# さくらちゃんのブロックくずし 🐦

ブロックをくずすと、下にかくれていたシマエナガのイラストが少しずつ見えてくる、
全 3 面のブロックくずし。

| 面 | 題名 | イラスト |
|---|---|---|
| 1 | ゆきのひ | 雪の上にちょこんと座る、大きな 1 羽 |
| 2 | えだのうえで | 雪の積もった枝に、2 羽がならんでとまる |
| 3 | さくらちゃんとなかま | 桜の枝で、さくらちゃん（「さくらちゃんの大横断」の主人公）と 2 羽がおしくらまんじゅう |

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。イラストも画像ファイルを
使わず、すべて Canvas2D のコードで描いている。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| ラケットを動かす | マウス / `← →` / `A D` | 指で横になぞる |
| 発射・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` | 画面下の ❚❚ ボタン |
| 消音 | `M` | 画面下の 🔊 ボタン |

- ボールを落とすと 1 つ減る（最初は 3 つ）。なくなるとゲームオーバー。
  「このステージをやりなおす」でその面の最初から（スコアも面の開始時に戻る）。
- 面をクリアするとイラストが全部見える。少し眺めてからタップで次の面へ。
- ハイスコアは難易度ごとに `localStorage` に保存。

## 難易度 ＝ ラケットの長さ

難しさは**ボールの速さではなく、ラケットの長さ**で決める。ボールの速さは全難易度・全面で同じ
（`BALL_SPEED = 330` px/秒）。

| 難易度 | 1 面 | 2 面 | 3 面 |
|---|---|---|---|
| かんたん | 120px | 108px | 96px |
| ふつう | 88px | 79px | 70px |
| むずかしい | 64px | 58px | 51px |

調整は `src/game/constants.ts` の 2 か所だけ：

- `DIFFICULTIES` … 難易度ごとの 1 面でのラケットの長さ
- `STAGE_PADDLE_SCALE` … 面が進むごとの倍率（`[1, 0.9, 0.8]`）

盤面の幅は 480px。ラケットの端で打つほど斜め（最大 60°）に飛ぶ。

### ブロックの並びと天井

- ブロックは 1 面 **80 個（8 列 × 10 段、1 個 56×28px）**。
- 天井（HUD の下端）といちばん上の段の間に **48px のすき間**（`TOP_GAP`）がある。
  縦 1 列を崩してボールがブロックの上に抜けると、天井とブロックの間で跳ね返りながら
  連続で崩せる（1 列だけ抜いた状態で試すと、天井で 3〜7 回跳ね返って 5〜13 個を連続で崩した）。

### 1 面にかかる時間の目安

ミスをしない自動操縦で 1 面 **約 2.6〜3.7 分**（12 段 96 個だったときは 3.5〜5 分）。
さらに短くしたいときは段を減らしてブロックを大きくする
（`BRICK_ROWS` と `BRICK_H` を変える。イラストの大きさは `BRICK_ROWS × BRICK_H` で決まる）。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + dist/ に静的ファイルを出力
```

## 公開

このリポジトリは**ソース管理用**。公開は会社サイトへ手動で配置する。

1. `npm run build`
2. `dist/` の中身を会社サイトの `files/games/002block/` にコピー
3. 会社サイト側でコミットして push

公開先: <https://rapid-apps.co.jp/games/002block/>

ファイル名にハッシュが付くため、**更新時は古い `assets/index-*.js` / `*.css` を消してから**コピーする。

## 構成

```
src/
  main.ts              エントリ。canvas 設定 / メインループ / カーソル
  style.css
  game/
    constants.ts       盤面・ブロック・ボール・難易度（ラケットの長さ）の定数
    levels.ts          3 面の定義（題名・イラスト・ブロックの色）
    art.ts             かくれているイラスト（シマエナガ、雪、枝、桜）を Canvas2D で描く
    game.ts            状態遷移・ボールの物理・当たり判定・スコア
    render.ts          盤面・HUD・タイトル／クリア／ゲームオーバー画面
    input.ts           マウス・タッチ（Pointer Events）・キーボード
    audio.ts           WebAudio の発振器だけで鳴らす効果音（音量は端末で切り替え）
    storage.ts         難易度ごとのハイスコア
    device.ts          タッチ端末かどうかの判定
public/
  thumbnail.webp       ゲームメニュー（/games/）用のサムネイル
```

### 設計メモ

- **ボールは 1 回 3px 以下の刻みで進めて判定する**。1 フレームで大きく動くと
  ブロックをすり抜けるため。1 刻みで壊すブロックは 1 つだけ。
- **速さは常に一定**。跳ね返りのたびに速さを 330 にそろえ、水平から 20° 未満に
  寝た角度は起こす（左右の壁の間を延々と往復しないように）。
- **イラストは毎フレーム描いて、その上にブロックを重ねる**だけ。壊したブロックの所から
  自然に見える。雪や花びらは時間で動く。
- **入力は Pointer Events に統一**。click を使わないので、タッチ後のゴーストクリックが起きない。
  指がキャンバスの外に出ても追えるよう `setPointerCapture` している。
