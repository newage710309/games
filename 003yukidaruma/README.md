# さくらちゃんの雪だるま退治 ⛄

氷のブロックを押してすべらせ、雪だるまをはさんでやっつける、ペンゴ風のパズルアクション。
全 3 面の固定迷路で、面をクリアするたびに短い幕間デモが流れる。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| 移動・氷を押す | 矢印キー / `WASD` | 画面下の十字キー（押したまま指をすべらせると向きが変わる） |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 右上の「❚❚ ポーズ」 | 右上の「❚❚ ポーズ」 |
| 消音 | `M` | ポーズ画面の「おと：オン／オフ」 |

- 進む先に氷があると押す。止まっている状態から押したときは**すぐに**すべる（割れる）。
  歩いてきてそのまま氷に当たったときだけ、**少し（0.22 秒）押し続けると**すべる（割れる）。
  そのあいだは、さくらちゃんが力をため、氷が小さくふるえる（歩いた勢いで押してしまわないように）。
  先が空いていればすべり、雪だるまを巻きこんで、止まったところでつぶす。
- 先がふさがっている氷を押すと、ひびが入って 4 つのかけらに割れて飛び散る（30 点）。雪だるまの卵が入った氷なら卵ごと消える（500 点）。
- 外周の壁に向かって押すと壁がゆれ、その壁ぎわにいる雪だるまが 4 秒間気絶する。
  気絶中の雪だるまにさわるとはじき飛ばせる（100 点）。
- 雪だるま（卵も含む）を全部やっつけるとクリア。早いほどボーナス。
- 雪だるまにさわるとミス（最初は 3 人）。ミスのあとは少しのあいだ点滅して、ぶつかっても平気。
- ゲームオーバーの「このステージをやりなおす」はその面の最初から。スコアは 0 に戻る。
  それまでの点数はゲームオーバーの時点でハイスコアに記録される（`localStorage`）。

## ルール（原作ペンゴからの取捨）

| ルール | 採用 | メモ |
|---|---|---|
| 氷を押すとすべり、雪だるまをはさんでつぶす | ○ | 一度に 2 体以上つぶすと 400 → 1600 → 3200 → 6400 点 |
| 動けない氷を押すと割れる | ○ | |
| 卵の入った氷（面の始めにピンクに点滅して場所を教える） | ○ | 盤面に出る雪だるまの数には上限があり、減ると卵がかえって補充される |
| 雪だるまも氷を壊す | ○ | たまに壊しにくる。閉じこめられたときも壊して出る（卵入りの氷は壊さない） |
| 時間がたつと雪だるまが速くなる | ○ | 30 秒ごとに 15%、最大 45%。速くなるとまゆ毛がつり上がる |
| 壁をゆらして気絶させる | ○ | |
| タイムボーナス | ○ | 1 分以内 5000 ／ 1 分半 2000 ／ 2 分 1000 ／ 3 分 500 |
| ダイヤブロック（3 つそろえるとボーナス） | × | 次の改善候補（桜の花ブロックに置きかえる案） |
| 最後の 1 体が逃げる | × | |
| 1 UP、16 面ループ | × | 全 3 面で完結 |
| 難易度選択 | × | 面ごとに少しずつ難しくなる |
| 幕間デモ | ○ | 各面のクリア後（下記） |

## 面と幕間デモ

| 面 | 題名 | 雪だるま（同時に） | 速さ（マス／秒） | クリア後のデモ |
|---|---|---|---|---|
| 1 | ゆきのはら | 5 体（2 体）※ | 2.0 | ころころ ゆきだるま（追いかけてきた雪だるまが転んで転がっていく） |
| 2 | こおりのめいろ | 7 体（3 体） | 2.4 | おいかけっこ（追われたさくらちゃんが、氷を押して反撃） |
| 3 | はるをまつもり | 9 体（3 体） | 2.7 | はるが きた（エンディング。雪がとけて桜が咲く） |

※ 1 面は序盤をやさしくしている。最初の 2 体は、スタート位置と同じ段の両端の卵（迷路の `F`）から必ずかえる。
段の上下は氷でふさいであるので、雪だるまは段の中を行き来し、スタートの左右の氷を押せばつぶせる
（反応が 1 秒以内なら、自動の試験で 40 回中 40 回とも最初の 2 体をつぶせた）。3 体目からはいつもどおり。

さくらちゃんの速さは 4.5 マス／秒。迷路と面ごとの設定は `src/game/levels.ts`、
時間・速さ・点数は `src/game/constants.ts` にまとめてある。

盤面は原作（13×15）より小さい **9×11 マス**、1 マス 48px にして、キャラクターを大きく見せている。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 型チェック + dist/ に静的ファイルを出力
```

開発時は、コンソールの `__game`（ゲームの状態）と `__seededRandom`（乱数の固定）で動きを再現して確かめられる。

## 公開

このリポジトリは**ソース管理用**。公開は会社サイトへ手動で配置する。

1. `npm run build`
2. `dist/` の中身を会社サイトの `files/games/003yukidaruma/` にコピー
3. 会社サイト側でコミットして push

公開先: <https://rapid-apps.co.jp/games/003yukidaruma/>

ファイル名にハッシュが付くため、**更新時は古い `assets/index-*.js` / `*.css` を消してから**コピーする。

### 設計メモ

- **歩いてきて氷に当たったときだけ、押すのにためが要る**（`PUSH_HOLD`）。止まったときの向きを `arrivedDir` に覚えておき、
  その向きのまま押し続けたときだけためる。いったん離す・止まったまま向きを変えると、次はすぐ押せる。
- **移動はマス単位**。マスの中心で押している向きを読むので、押しっぱなしなら止まらずに歩き続ける。
  歩いている途中でも、反対向きを押せばすぐ引き返せる。
- **十字キーは中心からのずれで向きを決める**。押したまま指をすべらせれば向きが変わる。
  `setPointerCapture` しているので、指が十字キーの外に出ても追いかける。斜めあたりでは、
  今の向きを少し優先して（ヒステリシス）向きがちらつかないようにしている。
- **すべる氷は 1 マスずつ進み、次のマスがふさがっていたら止まる**（壁・氷・別のすべる氷・さくらちゃん）。
  進む途中で前にいる雪だるまを巻きこみ、止まったところでまとめてつぶす。
- **雪だるまは分かれ道でだけ向きを決める**。面ごとの確率でさくらちゃんに近づく向きを選び、
  それ以外はでたらめに歩く（引き返すのは行き止まりのときだけ）。ほかの雪だるまと同じマスには入らない。
