# さくらちゃんのパークゴルフ ⛳

さくらちゃんが自分より大きい木のクラブを全身で振って、クマとキツネといっしょにパークゴルフ。
コースを真上から見て、1 打ずつ**坂を読んでねらう**ターン制のゲーム。春の川辺・秋の森・冬の雪の 3 コース、全 9 ホール
（ほんもののパークゴルフ 1 コース分）。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターもコースも画像ファイルを使わず、
すべて Canvas2D のコードで描いている（さくらちゃん・雪だるまはシャッターチャンス（011）の絵、クマはもちつき（009）、
キツネは森の案内係（005）の絵をコピーし、クラブを持つポーズ・ぼうし・拍手や顔をおおう腕などを描き足した）。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| 向きを合わせる | マウスで後ろへ引っぱる（引っぱる向きの反対へ打つ） / `←` `→` | 画面のどこでも左右にドラッグ（はなしても打たない。何度でも合わせなおせる） |
| 強さを決めて打つ | 引っぱった長さが強さ。はなすと打つ / `Space` 長押しで強さをためて、はなすと打つ | 画面のどこでも下へ引っぱり、はなすと打つ（長く引くほど強い） |
| コースを見わたす | 右上の「コースをみる」ボタン / `V`（見わたし中はドラッグ・`↑` `↓`） | 同じボタン（見わたし中は上下にドラッグ） |
| 打つのをやめる | 少しだけ引いてはなす | 下へ引いた指を、もとの高さまでもどしてはなす |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

- 引っぱっている間は、打つ向きの**短いガイド線**と強さメーターだけを出す。どう転がるかの予測線は出さない（坂を読むところを遊びとして残すため）。
- 強さは引っぱった長さで決まる（マウスは 150px、タッチは下へ 190px で最大）。`Space` 長押しの強さは 0 → 最大 → 0 と行き来する（2.4 秒で 1 往復）。
- タッチは、指を動かしはじめた向きで「向き」か「強さ」かを決める（10px 動かした時点で、横が大きければ向き、縦が大きければ強さ）。
  向きは指 1px で約 0.25° 回る（指の位置とは関係なく、いまの向きから回る）ので、ボールが指で隠れず、何度でも細かく合わせなおせる。
  強さを引いている間は向きが変わらない。
- 思いきり（強さ 92% 以上）打つと、さくらちゃんが勢いあまってくるっと回る。
- 左上の「❚❚」と右上の「コースをみる」は離して置いてあり、ボタンを押しても打つ操作は始まらない。

### 進め方

1. コースの始めに、コースの名前と目標打数を出す。
2. ホールの始めに、カップからティーまでカメラを流してホール全体を見せる（タップでとばせる）。
3. ホールが画面より長いときは、ボールに合わせてカメラが動く。「コースをみる」でいつでも見わたせる。
4. カップに入るまで打つ。1 ホールで打てるのは「パー＋3」打まで。入らなければ拾い上げて、パー＋3 打として数える。
5. 池・川・OB（白いくいの外）に入ると 1 打ペナルティで、入る手前からもう一度打つ。
6. 3 ホール回るとスコアカードを出す。1 ホールずつ打数を並べてから、合計とクリアかどうかを見せる。

- **コースの途中では終わらない。** 大たたきしても 3 ホールを最後まで回り、3 ホール目が終わったところで判定する。
- 合計打数が目標打数（パーの合計＋5 打）以内なら次のコースへ。超えたら「きょうは ここまで」でゲームオーバー（コンティニューなし）。
  クマとキツネが「また こんど いっしょに まわろう」となぐさめる。
- プレイ中は上の情報欄に「もくひょう ○打　いま ○打」と、あと何打まで大丈夫かを出す。

### コースにあるもの

| もの | 効果 | 出る面 |
|---|---|---|
| 芝（フェアウェイ） | ふつうに転がる | 1 めん〜 |
| ラフ | 転がりにくい | 1 めん〜 |
| 傾斜 | ボールが坂の下へ曲がる。下る向きに芝を濃くし、小さな矢印を流して見せる（強い坂は 2 重の矢印） | 1 めん〜 |
| 木・岩・切り株 | ボールがはね返る | 1 めん〜 |
| 池・川・OB | 1 打ペナルティで、入る手前からもう一度打つ | 1 めん〜 |
| 落ち葉 | よく止まるので、寄せに使える | 2 めん〜 |
| 小川と橋 | 小川は水（ペナルティ）。橋の上だけ渡れる | 2 めん〜 |
| 木の根のでこぼこ | 横切るとボールの向きが少し変わり、少し遅くなる（根ごとに曲がる向きが決まっている） | 2 めん〜 |
| 雪・氷 | 雪はすぐ止まり、氷はよくすべる。3 めんの圧雪の道は芝より少し転がりにくい | 3 めん |
| 雪だるま | 決まった道を一定の速さで往復してコースをふさぐ。当たるとはね返る | 3 めん |
| かまくらのトンネル | 入口のかまくらの穴に入ると、同じちょうちんの出口から出てくる。穴以外に当たるとはね返る | 3 めん |

- 運だけで決まるじゃまは入れていない。ボールの転がりは乱数を使わず、いつも 1/120 秒きざみで同じ計算をするので、
  同じ打ち方なら毎回同じ結果になる（動くのは雪だるまだけで、雪だるまの位置もホールの時計だけで決まる）。
- 地面の当たりは、描いた形（`src/game/holes.ts` の形）をそのまま使う。

### 仲間（クマとキツネ）

- 同じ組で回るが、見ているだけ。打つたびに反応する（寄せたら拍手、池ぽちゃ・OB で顔をおおう、雪だるまに当たるとあわてる、
  ホールインワンで大はしゃぎ）。
- キツネは 1 めんだけ、坂のある所に来ると小声でヒントをくれる（「カップの てまえ、右へ まがる 坂だよ」など）。

### きねんスタンプ

- 9 ホールそれぞれに「きねんスタンプ」がある。**バーディ以上**で、そのホールの緑の「ナイスショットきねん」を押す。
  **ホールインワン**なら、赤に金の星の「ホールインワンきねん」に格上げする（スタンプは下がらない）。
- 集めたスタンプは保存し、タイトル画面の「きねんスタンプ」から見られる（○ / 9 と、そのうちのホールインワンの数）。
- はじめは「ホールインワンを出したホールだけ」を集める仕組みだったが、ホールインワンが出せるのはパー 3 の 3 ホールだけなので、
  残りの 6 個が集められなかった。そこでバーディ以上で集められるようにし、ホールインワンは格上げにした。
- ボットで、9 ホールすべてでバーディが出ることを確かめた（30 回ずつ。ホールごとのバーディ以上の割合。はじめてのボットでは 3-2・3-3 は 0%）：

| ボット | 1-1 | 1-2 | 1-3 | 2-1 | 2-2 | 2-3 | 3-1 | 3-2 | 3-3 |
|---|---|---|---|---|---|---|---|---|---|
| はじめて | 70% | 30% | 20% | 36% | 11% | 4% | 30% | 0% | 0% |
| ふつう | 77% | 47% | 57% | 70% | 30% | 23% | 76% | 24% | 3% |
| じょうず | 93% | 90% | 80% | 97% | 73% | 37% | 90% | 60% | 17% |

  いちばんむずかしいのは 3-3（最後の 1 個）。かまくらのトンネルをうまく使うと、バーディがねらえる。

## デモ

- **1 めんのあと：** クマが「つぎは 森の コースだ！」と張りきる。
- **2 めんのあと：** 雪だるまが「ふゆは ゆきの コースで しょうぶだ！」と呼びに来る。
- **エンディング：** 9 ホール回って丸くなって休んでいたさくらちゃんを、クマが白いボールとまちがえてティーに置き、
  クラブをかまえる。目をさましたさくらちゃんがパタパタ飛んで「ボールじゃ ないよ！」と抗議したあと、みんなで記念写真。

### 仕様から変えたところ・決めたところ

- **★ はクリアしたコースだけ。** 目標打数を超えたコースは ★ なし。
- **3 めんのボールはオレンジ。** 白いボールだと雪の上で見えにくいため（ほんもののスノーパークゴルフも色つきのボールを使う）。エンディングの「白いボールとまちがえる」場面のボールは白のまま。
- **3 めんの圧雪の道は、芝より転がりにくくした（1.6 倍）。** 同じ芝のままだと、3 めんが 3 つの中でいちばんやさしくなったため。
- **Space 長押しの強さは 0 → 最大 → 0 と行き来する。** ためすぎても、はなす時をずらせばやりなおせるように。
- **スマホは「左右にドラッグで向き」「下へ引いてはなすと打つ」に分けた。** 仮公開して遊んでもらったところ、引っぱる 1 回で向きと強さを
  同時に決めるのがスマホでは難しく、引きはじめに矢印が逆を向いて混乱したため。強さをタイミングで決める方式にはせず、引いた長さで決める
  （坂を読んで決めた強さを、そのまま出せるように）。PC のマウス操作は前のまま。
- **エンディングで、クマがクラブを両手でにぎって振り上げるようにした。** 前はクラブだけが宙にういていた。
- **3-2 のかまくらの入口をティー寄りに動かし（入口の前を往復する雪だるまもいっしょに）、出口を少し手前にした。** 前の位置では、ティーから強さ最大でも
  ほとんど届かず、トンネルの近道が使えなかったため。
- **3-3 のかまくらの出口をカップに少し近づけた。** バーディのスタンプが、じょうずなボットでも 3% しか取れなかったため。
- **2-2 の橋を縦に長くし、2-3 の橋も少し広げた。** 仮公開で、2-2 の小川が橋のあたりで V 字に曲がっていて、
  橋の左下のすみで水が橋からはみ出し、橋の上を通ったボールが池ぽちゃになることがあったため。橋の上下に水が残っていないことを確かめた。
- **ホールの結果は、タップするまで出しておく。** ホールインワンの文字・紙ふぶき・スタンプをゆっくり見られるように。


## 開発

```bash
npm install
npm run dev          # http://localhost:5173/
npm run build        # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
npm run bot          # 腕前の違うボットを 30 回ずつ走らせて、上の表を出す（回数を変えるとき：npm run bot -- 50）
```

- `design.html`（開発時だけ）：場面ごとの画面と、さくらちゃんのポーズ・クラブ・ボール・カップと旗・ティー・クマとキツネ・
  雪だるま・かまくら・地面の種類・HUD・スコアカード・スタンプ・9 ホールの全体図の一覧。
- 開発時はコンソールから `__game`（状態）、`__render`、`__Bot`・`__SKILLS`（ボット）を使える。
- ホールの形と数値は `src/game/holes.ts`、得点・★・目標打数は `src/game/stages.ts`、ボールの転がりは `src/game/physics.ts`、
  地面の種類と当たりの形は `src/game/course.ts`、コースの絵は `src/game/field.ts` にまとめてある。
- ハイスコア・コースごとの最高 ★ と最少打数・きねんスタンプは localStorage に保存される
  （`sakura-parkgolf.highscore.v1`、`sakura-parkgolf.best.v1`、`sakura-parkgolf.stamps.v2`）。読み書きに失敗しても遊べる。
  前の版の `sakura-parkgolf.stamps.v1`（ホールインワンを出したホール）は、ホールインワンのスタンプとして引きつぐ。
- `public/og.jpg`：OGP 画像（1200×630）。`promo/parkgolf_promo.mp4`：告知動画（インスタのストーリー用、縦 1080×1920・30fps・約 17 秒・効果音つき。
  1-1 のホールインワン → 秋の森の橋 → 冬のかまくらのトンネル → タイトル）。
- OGP 画像と告知動画は、`promo.html`（開発時だけ）でゲームそのものを 1/30 秒ずつ動かして描く（`src/promo.ts`）。作り方：
  1. 画像を受け取って保存するローカルのサーバー（`http://localhost:5191/<ファイル名>` に POST された data URL を保存する）を立てる。
  2. `npm run dev` で `promo.html` を開き、コンソールで `await __makeOg()`（`og.jpg`）と `await __makeVideo()`（コマ `v_0000.jpg` … と音のきっかけ `promo_sounds.json`）を呼ぶ。
  3. `npm run promo -- <保存したフォルダ> promo/parkgolf_promo.mp4`。ゲームと同じ効果音（`src/game/audio.ts` の `TONES`）を WAV に合成し、
