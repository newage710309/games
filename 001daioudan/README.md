# さくらちゃんの大横断 🌸

フロッガー風のアクションゲーム。車の道路と流れる川を越えて、上の 5 つのお家に
桜色の小鳥「さくらちゃん」を送り届けよう。

（旧名「かえるちゃん」。キャラクターをカエルから桜色のシマエナガに変更した。）

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。ビルド成果物は
静的ファイルだけなので、GitHub Pages / Cloudflare Pages などにそのまま置ける。

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | `← ↑ ↓ →` または `W A S D` |
| 開始 / リスタート | `Space` / `Enter` / 画面クリック |
| ポーズ | `P` |
| 消音 | `M` |

### スマホ・タブレット

タッチ端末（`pointer: coarse`）では自動的にモバイル用 UI に切り替わる。

- **スワイプ**（盤面上、24px 以上動かす）または**画面の十字ボタン**で移動
- **タップ**でスタート／リスタート／ポーズ解除
- 十字ボタンの上段左右に**ポーズ**と**消音**ボタン
- **縦持ち**は盤面の下に十字ボタン、**横持ち**は盤面の横に並べて高さいっぱいまで使う
- `100dvh` 基準なのでアドレスバーの出入りでレイアウトが崩れない。ノッチ端末は
  `env(safe-area-inset-*)` でよける
- 引っ張って更新・バウンススクロール・ダブルタップズーム・長押しメニューは抑止済み
- `touchend` の直後にブラウザが合成する click（ゴーストクリック）は捨てているので、
  1 タップでゲームが 2 回開始されることはない
- 効果音は最初のタッチで AudioContext を解錠する（iOS の自動再生制限対策）

### ルール

- 道路では**車に当たるとミス**。川では**丸太か亀に乗っていないと溺れる**。
- 亀は数匹が定期的に**水に潜る**。潜っている間に乗っているとミス。
- 乗り物ごと**画面外に流されてもミス**。
- 制限時間は 1 機あたり 30 秒。
- 5 つのお家をすべて埋めるとレベルクリア。レベルごとに全体が 15% ずつ速くなる。
- 全体の速さは `constants.ts` の `BASE_SPEED`（既定 `0.5`）だけで調整できる。
  `level.ts` の各レーンの速度にこの値を掛けたものがレベル 1 の速さになる。

### 得点

| 行動 | 点 |
|---|---|
| 前に 1 マス進む（自己最高更新時） | 10 |
| お家に到着 | 50 + 残り秒数 × 10 |
| ハエを食べながら到着 | +200 |
| レベルクリア | +1000 |

ハイスコアは `localStorage` に保存される。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # 型チェック + dist/ に静的ファイルを出力
npm run preview  # dist/ の確認
```

Node.js 18 以上が必要。

## 公開

このリポジトリは**ソース管理用**。公開は別リポジトリ（会社サイト）へ手動で配置する。

1. `npm run build`
2. `dist/` の中身を会社サイトの `files/games/001daioudan/` にコピー
3. 会社サイト側でコミットして push

公開先: <https://rapid-apps.co.jp/games/001daioudan/>

ファイル名にハッシュが付くため、**更新時は古い `assets/index-*.js` を消してから**
コピーすること。消さないと使われないファイルが溜まっていく。

`vite.config.ts` で `base: './'` にしてあるので、どの階層に置いてもそのまま動く
（`https://example.com/games/001daioudan/` のようなサブパス配信でも可）。

## 構成

```
src/
  main.ts              エントリ。canvas 設定 / メインループ
  style.css
  game/
    constants.ts       盤面サイズ・行レイアウト・得点などの定数
    level.ts           レーン定義とオブジェクト位置の計算（亀の潜水も含む）
    game.ts            ゲーム状態・移動・当たり判定・スコア
    render.ts          Canvas2D 描画（画像アセットなし、全部コードで描画）
    input.ts           キーボード / スワイプ / 画面ボタン
    audio.ts           WebAudio の発振器だけで鳴らす効果音（音量は MASTER_GAIN_*）
    storage.ts         ハイスコアの保存
    device.ts          タッチ端末かどうかの判定（案内文と音量の切り替えに使う）
public/
  thumbnail.webp       ゲームメニュー（/games/）用のサムネイル。ビルドで dist/ 直下に出る
```

### 設計メモ

- **レーンは生成/破棄しない**。等間隔に並べた N 個を `spacing * count` で剰余
  折り返しするだけなので、オブジェクト数は常に一定で GC 圧もない。
  `validateLanes()` が「折り返し幅 ≧ 画面幅 + オブジェクト幅」を開発時に検証する。
- **アセットが 1 つもない**。画像も音声ファイルも使わず Canvas2D と WebAudio で
  描画・発音するので、配信は HTML + JS + CSS のみ。
- **効果音は「持続区間つき」のエンベロープ**。立ち上がり直後から指数減衰させると
  カーブがすぐ落ちきって、ピークをいくら上げても実効音量（RMS）が上がらず
  小さく聞こえる。`SUSTAIN` の区間だけ音量を保ってから減衰させている。
  最終段の `DynamicsCompressor` が歪みを防ぐ。
  スマホのスピーカーは 200Hz 以下がほぼ鳴らないので、下降スイープも 120Hz 止まり。
- **音量は端末で分ける**。スマホの内蔵スピーカーに合わせると PC では大きすぎるため、
  `MASTER_GAIN_TOUCH`（既定 `0.8`）と `MASTER_GAIN_DESKTOP`（既定 `0.3`）を
  `device.ts` の判定で切り替えている。うるさい／小さいときはこの 2 つだけ触ればよい。
- **ホップ中は当たり判定を止める**（約 90ms）。空中扱いにして理不尽な当たりを防ぐ。
- **dt は 50ms で頭打ち**。タブ復帰時に時間が飛んでも判定がすり抜けない。
