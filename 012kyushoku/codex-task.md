## 見た目（確認ずみ。これを本体で使う）

絵と配置は、`012kyushoku/design.html`（`src/design.ts`）で確認ずみ。描画コードは次のファイルにある。本体はこれらの関数を呼んで描く。

- **`src/game/constants.ts`：** 画面の配置。
  - 上から順に、情報欄、給食室（奥の長テーブル・列・さくらちゃん）、カウンターがある。
  - カウンターは上から、「どうぞ！」の横長ボタン（`SERVE_BTN`、器の上）、トレー（`TRAY`）と器の順に並ぶ。
  - その下に鍋が並ぶ。
  - 器と「こうかん」ボタンの位置は `bowlLayout(n)`、鍋の位置は `potLayout(n)` で決める。
  - 列の位置は `FRONT_X`・`QUEUE_XS`・`QUEUE_Y`、さくらちゃんの位置は `SAKURA_POS`、奥の席は `SEAT_XS`・`SEAT_Y`。
  - 目盛りの値は `MARKS`。
- **`src/game/kitchen.ts`：** 次のものを描く。
  - 背景（`drawRoom`）と、奥の長テーブルの手前の板（`drawTableFront`。座った子を描いたあとに描く）
  - カウンター（`drawCounter`）とトレー（`drawTray`）
  - 「どうぞ！」（`drawServeButton`。オレンジ色の横長。空のときは灰色）
  - 「こうかん」（`drawSwapButton`）
  - 情報欄（`drawHud`）とポーズボタン
  - 面の名前の帯（`drawStageBanner`）とヒント（`drawHint`）
- **`src/game/food.ts`：** 品の種類・名前・汁ものかどうか・熱いかどうかの表と、次の描画。
  - 器（`drawBowl`）：中身の高さ、目盛り、山盛り、よそっているときの流れ
  - 鍋（`drawPot`）：「あと ○人ぶん」、残りわずかでカタカタ、押しているとき、キーの印
- **`src/game/kids.ts`：** 森の子（`drawKid`）。
  - リアクションは、ふつう・にっこり・もぐもぐ・しょんぼり・そわそわ・溶けかけ（雪だるま）。
  - 大きさの表は `KID_SCALE`、背の高さは `kidHeight`。
  - 頭の上のものも描く：待ち時間のゲージ（`drawWaitGauge`）、注文の吹き出し（`drawBubble`）、「ぐぅ〜」（`drawHungry`）、評価（`drawRating`）。
- **`src/game/chef.ts`：** さくらちゃん（`drawChef`）。給食帽・エプロン・おたまをつけている。
  - 当番中、器を下げる、クリア
  - 自分の給食を食べる、おなかいっぱい、少なくてしょんぼり、空のお皿でしょんぼり
- **既存作からコピーした絵：** `sakura.ts`、`birds.ts`、`guests.ts`、`bear.ts`、`snowman.ts`。`kids.ts` と `chef.ts` から使う。

### 決まったこと

- **見た目は design.html のとおりにする。** 描画の関数は、必要なら引数を足したり直したりしてよい。そのときは `src/design.ts` も合わせて直し、design.html が引き続き表示できるようにする。
- **こうかん：**
  - 器ごとに、下に「こうかん」ボタンがある。押した器だけを空の器に取りかえる。
  - `X` キーは、最後によそった器を取りかえる。
  - 取りかえるあいだ、さくらちゃんは少しのあいだ `swap` の姿になる。
- **キー：** 鍋は左から `1` `2` `3` `4`。「どうぞ！」は `Space`。
- **目盛り：** 1 めんは濃く、名前つき（`marks: 1`）。2 めんからは薄くする（`marks: 0.35`）。
- **列：** 先頭の子だけがお盆を置き、ほかの子はお盆を持って（`tray: true`）並ぶ。2 番目からは `QUEUE_XS` に並び、5 番目より後ろの子は画面の外で待つ。
- **渡したあと：**
  - 子は、頭の上に評価を出しながら奥の席へ歩いていく（`drawRating`）。
  - 席に座り、評価に合わせたリアクションで食べる。ぴったり・いいねなら、もぐもぐとにっこりを交互に。まあまあなら、もぐもぐ。
  - 席がいっぱいになったら、古い子から立って帰る。
  - ゲームは止めない。
- **待ち時間：** ゲージの残りが 25% を切ったら、その子のリアクションを「そわそわ」にする。
- **熱いもの：** 雪だるまに熱いもの（`FOOD_HOT`）を渡したら、「溶けかけ」にして、がっかり（ゲームオーバー）。
- **おなかが鳴っている子：**
  - 列に並んでいるあいだも、カウンターに来てからも、「ぐぅ〜」を出す。
  - いちばん多い段階（おおもり）の子は、おなかを鳴らさない。
- **さくらちゃんの分：** 最後に、鍋に残った分でさくらちゃんが食べる場面を出す（`eat` → `full` / `little` / `empty`）。
  - 鍋が複数のときは、本体の鍋（スープ・シチュー）の残りで判定する。
- **3 めんの割りこみ：**
  - おかわりで割りこむ子は、列の 2 番目に入り、「ちょっとだけ！」の吹き出しを出す。
  - 欲しいのは本体の鍋（シチュー）をすくなめで、好物はいらない。
  - 割りこみも、その面の人数（18 人）に数える。決まった順番で出し、鍋の量の計算にも入れる。
- **よそう速さ：** 品ごとに変える（仮の値、器の深さに対する割合／秒）。
  - スープ・シチュー：0.42
  - どんぐり・にんじん・あぶらあげ・かき氷：0.32
  - はちみつ：0.2
- **こぼれ：** 器は深さの 125% まで入る。それ以上は入らず、鍋も減らない。
- **「あと ○人ぶん」：** 鍋の残りを、その鍋の品の「ふつう」の量（0.55）で割った数（切り捨て）。
  - これからよそう子の分に足りなくなりそうになったら、`low`（カタカタ）にする。たとえば、残りの子の「ちょうどいい量」の合計の 110% を下回ったとき。
  - 早めに気づけるようにする。

## 作るもの

- **ゲーム本体：** `index.html`、`src/main.ts`、`src/game/` 一式。
  - 分け方は 011 にならう：`game.ts`、`render.ts`、`input.ts`、`audio.ts`、`stages.ts`、`demo.ts`、`bot.ts`、`storage.ts`、`ui.ts`、`device.ts` など。
  - 量の判定と採点は `serving.ts` にまとめる。
- **画面：** タイトル、面のはじめ、遊ぶ画面、面クリア（★ と内訳）、がっかり（ゲームオーバー。コンティニューなし）、ポーズ、デモ（1 めんのあと・2 めんのあと・エンディング）。
  - ポーズは `P` / `Esc` / 左上の「❚❚」。
  - 消音は `M`。スマホは、ポーズ画面の「おと：ON／OFF」。
  - タブが見えなくなったら自動でポーズする。
- **入力：** マウス・タッチの長押し（指ごとに追う）と、キーの押しっぱなし。
  - よそえる鍋は一度に 1 つ。2 つ同時に押したら、あとから押したほうを無視する。
- **音：** 011 の `audio.ts` にならい、Web Audio で作る。
  - よそう音（品ごとに少し変える）、どうぞ、ぴったり、いいね、まあまあ、がっかり
  - こうかん、鍋のカタカタ、おなかの音、面クリア
- **保存：** 各面の最高の ★ とハイスコア。読み書きに失敗しても遊べるようにする。キーの頭は `sakura-kyushoku`。
- **自動プレイのボット：** `src/game/bot.ts`、`tools/bot.ts`、`npm run bot`（`package.json` にすでにある）。
  - 腕前は 3 つで分ける。
    - 離すタイミングのずれの大きさ
    - 判断するまでの遅さ
    - 種類をまちがえる割合
  - まちがえたときは、ボットも「こうかん」で直す。
  - 腕前の段階は「はじめて」「ふつう」「じょうず」の 3 つ。ほかに、毎回少し多め（+8% くらい）によそう「もりすぎ」のボットも作る。
  - `npm run bot` で、腕前ごとに 30 回（引数で変えられる）走らせて表にする。
    - 面ごとの到達率・クリア率・★ の分布・平均点
    - がっかりの理由の内訳（ずれ・まちがい・時間切れ・鍋が足りない・熱いもの）
    - さくらちゃんが「おなかいっぱい」になった割合
  - 乱数は種を固定できるようにする（`new Game(audio, { headless: true, seed })`。011 と同じ形）。
  - ゲームの進行は DOM なしで動くようにする。
- **開発時の口：** コンソールから使える `__game`、`__render`、`__Bot`、`__SKILLS`（011 の `src/main.ts` にならう）。
  - 宣伝動画の録画に使うので、種を指定して最初から遊ばせる方法も用意する。たとえば `__game.startRun(seed)` と、ボットを画面の上で動かす `__autoplay(skillName, seed)` など。
  - どう使うかは最後の報告に書く。
