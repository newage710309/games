# さくらちゃんの給食当番 🌸

森の学校の給食室で、さくらちゃんが給食当番。並んだ森の子たち一人ひとりに、ちょうどいい種類と量の給食をよそおう。
最後に鍋に残った分が、さくらちゃんの給食になる。盛りすぎると、さくらちゃんの分も、あとの子の分もなくなってしまう。全 3 面。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も画像ファイルを使わず、
すべて Canvas2D のコードで描いている。

- **既存作の絵：** そのまま使っている。
  - さくらちゃん・雪だるま・小鳥：シャッターチャンス（011）
  - リス・ウサギ・キツネ：案内係（005）
  - クマ：もちつき（009）
- **描き足したもの：**
  - さくらちゃん：給食帽・エプロン・おたま、しょんぼりした目
  - 雪だるま：溶けかけの姿
  - 給食室、鍋、器、食べ物

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| よそう | 鍋を長押し / `1` `2` `3` `4` を押したまま | 鍋を長押し |
| 渡す | 「どうぞ！」ボタン / `Space` | 「どうぞ！」ボタンをタップ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

- **よそう：** 鍋を押しているあいだ、その鍋の品が、トレーの同じ並びの器にどんどん入る。
  - 離したあとも同じ品を足せるが、減らすことはできない。
  - よそえる鍋は一度に 1 つ。2 つ同時に押したら、あとから押したほうを無視する。
- **取りかえはできない。** よそった分は減らせないし、器を取りかえることもできない。ちがう鍋をうっかり押しても、すぐ離せば（器の深さの 1 割未満なら）見のがしてもらえる。
- **画面の並び：** 上から、列に並ぶ子、「どうぞ！」の横長ボタン、トレーと器、鍋。
  - 「どうぞ！」は器の上に置き、長押しする鍋からは離した。

### 1 人ぶんの流れ

1. 列の先頭の子がカウンターに来る。頭の上に待ち時間のゲージが出て、減っていく。
   - 残りが 25% を切ると、足ぶみしてそわそわする。
2. 見た目から、何をどれだけよそうかを決める。
   - **量：** 体の大きさで決まる。おなかが鳴っている子（「ぐぅ〜」）は 1 段階多くする。
   - **種類：** 動物から連想できる好物。
   - **3 めんの注文：** 頭の上の吹き出しに出る。注文があるときは、見た目より注文を優先する。量の注文は、その子のいつもの量とはちがう量だけにする（小鳥の「すくなめ」、クマの「おおもり」のような、いつもどおりの注文は出さない）。
3. 「どうぞ！」で渡す。子は頭の上に評価を出しながら、奥の席へ歩いていって食べる。ゲームは止まらない。

| 子 | 量 | 好物 |
|---|---|---|
| エナガ・ヤマガラ | すくなめ | なし（スープ／シチューだけ） |
| リス | すくなめ | どんぐり |
| ウサギ | ふつう | にんじん |
| キツネ | ふつう | あぶらあげ |
| クマ | おおもり | はちみつ |
| 雪だるま | ― | かき氷だけ（ふつう）。熱いものは溶けかけるので、がっかり |

- **ちょうどいい量：** 器の深さに対して、すくなめ 30%、ふつう 55%、おおもり 85%。器の内側に 3 本の目盛りがある。1 めんははっきり名前つき。2 めんからは少し薄くして、器の左に頭の 1 文字（す・ふ・お）を添える。
- **好物の量：** 本体（スープ・シチュー）と同じ段階。
- **器：** 深さの 125% まで入る（ふちから山盛りになる）。
- **よそう速さ：** 品によって変えた（器の深さに対する割合／秒）。
  - スープ 0.75、シチュー 0.72
  - どんぐり・にんじん・あぶらあげ・かき氷 0.58
  - とろとろのはちみつは 0.38

### 1 人ごとの評価

品ごとに、ちょうどいい量からのずれ（器の深さに対する割合）を見る。

| 量のずれ | 評価 | 点 |
|---|---|---|
| ±5% 以内 | ぴったり！ | 100 |
| ±12% 以内 | いいね | 60 |
| ±36% 以内、または多すぎ | まあまあ | 20 |

- **2 品以上のとき：** 点はその平均で、評価はいちばん悪い品に合わせる。
- **がっかり：** 次のどれかで「がっかり」になり、**その場でゲームオーバー**（コンティニューなし）。
  - 少なすぎた（ちょうどいい量より 36% を超えて少ない）、または食べる品を空のまま渡した
  - 食べない品をよそったまま渡した（器の深さの 1 割以上。それより少なければ、入っていないものとして見る）
  - 待ち時間が切れた
  - 雪だるまに熱いものを渡した
  - 鍋がなくなった（下の「鍋の残り」）
- **多めによそったとき：** どれだけ多くても「まあまあ」までで、がっかりにはならない。そのかわり鍋が早くなくなる。
- **1 段階のまちがい：** 量を 1 段階まちがえた（おなかの音を見落とした、など）だけなら、少しずれていても「まあまあ」で、ゲームは続く。
- **がっかりの画面：** 何をどれだけよそえばよかったかを出す（例：「スープは 『ふつう』 だったよ」「おなかが なってる子は 1だん おおめ」）。
  - 2 品ほしい子に、1 品を空のまま渡したときは「あぶらあげも あげてね」「あぶらあげは 『ふつう』 だったよ」と出す。
  - さくらちゃんは、がっかりの瞬間に驚いた顔（見開いた目・開いたくちばし・広げた羽・「！」・ひや汗）で跳び上がる。
  - ゲームオーバーのパネルはカウンターから下に出し、上の驚いたさくらちゃんとしょんぼりした子が見えるようにした。

### 鍋の残りと、さくらちゃんの分

- **鍋の量：** その面の全員の「ちょうどいい量」の合計に、さくらちゃんの分（本体の鍋だけ、ふつう 0.55）と、ゆとりを足した量。
  - ゆとりは割合ではなく量で、1 めん 0.45、2 めん 0.35、3 めん 0.25（器の深さに対する割合。鍋ごと）。
  - 全員にぴったりよそえば、本体の鍋にはさくらちゃんの分＋ゆとり（ふつう 1 杯とすこし）が残る。
- **残りは数字で出さない。** 鍋の中身の表面の高さで見えるだけ。
- **鍋がなくなったら：** 鍋が空になると、それ以上はよそえない。次の子がカウンターに来たとき、その子の分が鍋に残っていなければ
  （残りでは「まあまあ」にも届かなければ）、さくらちゃんが「スープが なくなった！」と驚いて、がっかり（ゲームオーバー）。
  - よそっているとちゅうで空になり、少なすぎるまま渡したときも、同じく「なくなった」になる。
- **カタカタ：** ゆとりを半分より多く使ってしまう（残りが、これから来る子の分＋ゆとりの半分を下回る。本体の鍋はさくらちゃんの分も足す）と、鍋がカタカタ揺れる。
- **さくらちゃんの分：** 全員に配り終えたら、本体の鍋（スープ・シチュー）に残った分が、さくらちゃんの給食になる。
  - 残りが「ふつう」以上なら、おなかいっぱい（＋500 点）。★★★ にはこれも要る。
  - 足りなければ、しょんぼり食べる。
  - 0 以下なら、空のお皿を見てしょんぼりする。
  - どの場合もゲームオーバーにはならない。

## 面

| 面 | 舞台 | 鍋 | 並ぶ子（人数） | 新しく出るもの |
|---|---|---|---|---|
| 1 めん | 朝の給食室 | スープ | 小鳥 3・リス 2・ウサギ 4・クマ 3（12 人）。おなかが鳴る子 3 人 | 体の大きさで量を見分ける、おなかの音 |
| 2 めん | 大にぎわいの日 | スープ・どんぐり・にんじん | 小鳥 4・リス 5・ウサギ 6（15 人）。おなかが鳴る子 4 人 | 好物の種類、鍋の持ちかえ |
| 3 めん | ゆきまつりの特別給食 | シチュー・あぶらあげ・はちみつ・かき氷 | 小鳥 4・キツネ 5・クマ 4・雪だるま 2・おかわり 3（18 人）。注文のある子 6 人 | 注文、おかわり、雪だるま |

- **並ぶ順番：** 人数は面ごとに決まっていて、順番は乱数でまぜる。同じ種類は 3 人以上つづかない。
- **ゆっくりの場面：** 1 めんの最初の 3 人は、すくなめ・ふつう・おおもりを 1 人ずつ、ゆっくり出す（待ち時間はその面の ＋2 秒）。
  - 新しいしかけの最初の 1 回も、ヒントを出し、待ち時間をその面の ＋2 秒にする。
- **待ち時間：** ふつうは、1 めん 8 秒、2 めん 9 秒、3 めん 10 秒。
- **3 めんのおかわり：** 食べ終えた子が席から立って列に割りこみ、シチューすくなめをもらいに来る。吹き出しは、好物のある子（キツネ・クマ）が「シチュー おかわり！」、小鳥が「おかわり！」。最初のおかわりで「おかわりは すくなめ」のヒントを出す。好物（あぶらあげ・はちみつ）は入れても入れなくてもよい（点には数えない）。
- **デモ：**
  - 1 めんのあと：みんなで「ごちそうさまでした！」。席からハートが飛んできて、さくらちゃんが「えへへ…」と照れる。黒板が「あしたの こんだて（スープ・どんぐり・にんじん）」に変わり、リスとウサギが前に出てきて喜ぶ（2 めんの予告）。
  - 2 めんのあと：ゆきまつりのお知らせ。さくらちゃんが振り向くと、列のうしろの雪だるまが止まる。
  - エンディング：雪だるまがシチューの鍋ごと持っていこうとして溶けかける。外へ出て、小鳥・キツネ・クマが雪玉を転がしてきて足すと、元の姿にもどる。最後は外でみんなでいただきます（雪だるまはかき氷）。

## 得点と ★

| 内容 | 点数 |
|---|---|
| 1 人ごとの評価 | ぴったり 100／いいね 60／まあまあ 20 |
| 残り時間ボーナス（1 人ごと） | 待ちゲージが 3/4 より多く残っているあいだだけ。満タンなら ＋30、残り 87.5% なら ＋15、3/4 以下は 0。「はやい +○」と出る |
| さくらちゃんが「おなかいっぱい」 | ＋500 |
| 面クリア | ＋500 |

★ は、その面の 1 人あたりの平均点で決める（残り時間ボーナスは平均点に入れない）。

| ★ | 条件 |
|---|---|
| ★ | 平均 60 点以上 |
| ★★ | 平均 75 点以上 |
| ★★★ | 平均 95 点以上で、さくらちゃんも「おなかいっぱい」 |

### 仕様から変えたところ

試遊で「簡単すぎる」となったので、仕様の目安から次のように難しくした。

- **★★★ の基準を、平均 90 点から 95 点に上げた。**
- **よそう速さを上げた。** 仕様の目安（スープ 0.42 など）の約 1.8 倍。離すタイミングの差が点に出る。
- **「いいね」の幅をせまく、「まあまあ」の幅を広くした。** ±15%／±30% を ±12%／±36% にした。
  一度 ±25% にせばめたが、おなかの音を見落として 1 段階少なくよそうと（ずれ 0.30 前後）すぐゲームオーバーになった。仕様の「がっかりははっきりした失敗だけ」に合わないので、1 段階のまちがいは少しずれても「まあまあ」で済む幅にもどした。
  かわりに、食べる品を空のまま渡したら、量にかかわらずがっかりにする。
- **鍋のゆとりを、割合ではなく量にした。** 仕様の「＋20／15／10%」は人数が多いほど大きくなり、ぴったりよそっても 1 めんの最後に「あと 3人ぶん」残った。
  ゆとりを 0.45／0.35／0.25 の量にして、ぴったりなら、さくらちゃんの分＋すこしが残るようにした。
- **「あと ○人ぶん」の札をなくした。** 残りは鍋の中身の高さと、カタカタだけで知らせる。試遊のあとに決めた。
- **「こうかん」ボタンをなくした。** 試遊のあとに決めた。器はそのぶん大きくした（深さ 1 めん 100、2 めんから 92）。
  取り返しがつかなくなるので、食べない品が器の深さの 1 割未満なら見のがすことにした（熱いものを雪だるまに渡したときも同じ）。
- **多めによそっても、がっかりにしない。** 仕様は「ずれが ±30% を超えたらがっかり」で、多すぎも少なすぎも同じだった。
  多すぎは「まあまあ」までにして、そのかわり鍋がなくなったら「○○が なくなった！」でがっかりにした（試遊のあとに決めた）。
- **待ち時間を短くした。** はじめの 24〜28 秒を 12〜16 秒にし、さらに 8〜10 秒にした（最初の場面とヒントのある場面は、その面の ＋2 秒）。
- **おなかが鳴る子と、注文のある子を増やした。** 1 めん 2→3 人、2 めん 2→4 人、3 めんの注文 4→6 人。
- **2 めんのヒントを 2 つにした。** 「リスは どんぐりも。スープと おなじ すくなめ」「ウサギは にんじんも。スープと おなじ ふつう」。好物の量が分からないという声があったので。
- **カウンターの子の「ぐぅ〜」を大きくした。** 子の左（さくらちゃんとのあいだ）に 1.45 倍で出す。2 番目の子と重ならない。
- **2 めんからの目盛りを濃くした。** 仕様では薄くだったが、どの線がどの量か見分けにくかった。濃さ 0.75（3 めん 0.55）にして、頭の 1 文字を添えた。

## ボットでの確認結果

`npm run bot` で、腕前の違うボットを 30 回ずつ走らせた結果（`src/game/bot.ts`）。

- **何を見るか：** ボットは、子の「ちょうどいい量」を知っている。そのうえで、人のまちがいをまねる。
- **腕前を分けるもの：**
  - 離すタイミングのずれ（秒。よそう速さを掛けると量のずれになる）
  - 判断するまでの遅さ
  - まちがえる割合：ちがう鍋を押す（気づいてすぐ離す。判断の遅さの 2 割の時間だけ入る）、おなかの音や注文を見落として 1 段階ちがう量にする（気づかずに渡す）
- **「もりすぎ」：** タイミングは「ふつう」と同じで、毎回ねらいより 10% 多くよそう。

| ボット | 離すタイミングのずれ | 判断の遅さ | まちがえる割合 |
|---|---|---|---|
| はじめて | ±0.26 秒 | 0.7 秒 | 8% |
| ふつう | ±0.16 秒 | 0.4 秒 | 4% |
| じょうず | ±0.09 秒 | 0.2 秒 | 1.5% |
| もりすぎ | ±0.16 秒、いつも ＋10% | 0.4 秒 | 4% |

| はじめて | 2 めん | 29 | 93% | 10／17／0／0 | 60.4 | 70% | ずれ 2 |

（「クリア」は、その面にとどいた回のうちクリアした割合。）

- **はじめて：** 1 めんはほぼクリアできる。エンディングまで行けるのは 8 割近く。★★ 以上は取れない。
  3 めんでは、雪だるまにうっかりシチューの鍋を押して、離すのが遅れると（1 割を超えると）溶けてがっかりになる。
- **ふつう：** 毎回エンディングまで行けるが、★★★ は 1 度も取れない。
- **じょうず：** ★★★ は面ごとに 2 割前後（3 めんは 30 回中 5 回）。
  - このボットは離すタイミングのずれが ±0.09 秒しかなく、目盛りを見まちがえることもないので、人より正確。人ではもっと取りにくいはず。
- **もりすぎ：** 毎回 10% 多くよそうと、1 めんの終盤で半分が「なくなった」になり、2 めんはほぼクリアできない。量を合わせられるボットは、さくらちゃんの分まで残せる。
- **待ち時間：** 1 人ぶんにかかった時間は、ボットで 1.2〜2.8 秒。渡したときの待ち時間の残りは、最小でも 40%（はじめて）。時間切れは 0 回。
- **ブラウザで確かめたこと：**
  - 全 3 面、デモ、エンディング、ゲームオーバー、ポーズを動かした。
  - スマホ幅（375×812）で、はみ出さないことと、3 めんの鍋 4 つが押せる大きさで並ぶことを確かめた。
  - マウスの長押し、`1` `P` `M` キーの動きを確かめた。

## 開発

```bash
npm install
npm run dev          # http://localhost:5173/
npm run build        # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
npm run bot          # 腕前の違うボットを 30 回ずつ走らせて、上の表を出す（回数を変えるとき：npm run bot -- 50）
```

- **確認用のページ（開発時だけ）：**
  - `design.html`：場面ごとの画面と、さくらちゃん・森の子とリアクション・雪だるま・鍋・器・食べ物・評価・背景の一覧。
  - `tools/check-customers.ts`：各面の並ぶ子の人数と順番の決まりを、たくさんの乱数で確かめる。
- **コンソールから使える口（開発時だけ）：**
  - `__game`（状態）、`__render`、`__Bot`・`__SKILLS`
  - `__autoplay('ふつう', 種)`：種を決めてボットに遊ばせる。`__stopAutoplay()` で止める。
- **数値と処理の置き場所：**
  - 数値と並ぶ子の作り方：`src/game/stages.ts`
  - 量の判定と採点：`src/game/serving.ts`
  - 配置：`src/game/constants.ts`
- **保存：** 各面の最高の ★・ハイスコア・消音は localStorage に保存される（キーの頭は `sakura-kyushoku`）。

### OGP 画像・サムネイル・宣伝動画の作り方

どれも `tools/promo.html`（開発時だけ。ビルドには含めない）で、ゲームの描画コードを使って作る。

1. `npm run dev` で開発サーバーを立ち上げ、Chrome 系のブラウザで `http://localhost:5173/tools/promo.html` を開く。
2. **宣伝動画：** 「録画」を押すと、約 12.6 秒の動画を MediaRecorder（mp4 / H.264 + AAC）で録る。
   - 終わったら「kyushoku_promo.mp4 を保存」から保存し、`promo/kyushoku_promo.mp4` に置く。
   - タブが裏にあると、コマが落ちる。録画のあいだはタブを表に出しておく。
   - 先に一度ページをクリックすると、音が出る。
   - ゲームの場面は、乱数を固定（種 4・9）してボット（じょうず）に遊ばせたもの。テンポよく見せるため、1.45 倍の速さで進めている。
   - 構成：タイトル → 長押しでよそって「ぴったり！」が続く（1 めん）→ 盛りすぎて本体の鍋がカタカタ（3 めん）→ さくらちゃんが自分の給食を食べる → ゲーム名で締める。
3. **OGP 画像とサムネイル：** コンソールで次を呼ぶ。返ってくる data URL を保存する。
   - `__makeOg()`：`public/og.jpg`（1200×630）
   - `__makeThumb()`：`public/thumbnail.webp`（480×640。1 めんで「ぴったり！」が出た瞬間のゲーム画面）

- `promo/kyushoku_promo.mp4`：宣伝動画（縦 1080×1920・約 12.6 秒・効果音つき）。`public/` には入れない。

## 公開

このリポジトリは**ソース管理用**。公開は会社サイトへ手動で配置する。

1. `npm run build`
2. `dist/` の中身を会社サイトの `files/games/012kyushoku/` にコピー
3. 会社サイト側でコミットして push
