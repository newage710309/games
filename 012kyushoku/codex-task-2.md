## 3. ゲームの進行で足りないところ

- **並ぶ子の順番：** 今は種類を順にくり返しているだけなので、種で決まる乱数でまぜる。ただし、面ごとに決まりを持たせる。
  - **1 めんの最初の 3 人：** すくなめ（小鳥）・ふつう（ウサギ）・おおもり（クマ）を 1 人ずつ。待ち時間を長くして、ゆっくり出す。
  - **新しいしかけの最初の 1 回：** 待ち時間を長くし、ヒント（`drawHint`）を出す。前後の子は、それ以外のしかけのない子にする。
    - 1 めん：はじめておなかが鳴っている子 → 「おなかが なってる子は 1だん おおめに」
    - 2 めん：はじめて好物がある子 → 「リスは どんぐり、ウサギは にんじん も」
    - 3 めん：はじめての注文 → 「ちゅうもんが あるときは ちゅうもんどおりに」
    - 3 めん：はじめてのおかわり → 「おかわりは ちょっとだけ」
    - 3 めん：はじめての雪だるま → 「ゆきだるまは かき氷だけ。あついものは だめ」
- **3 めんの子の好物：**
  - キツネ → あぶらあげ、クマ → はちみつ
  - 小鳥 → シチューだけ
  - 雪だるま → かき氷だけ（ふつう）
- **3 めんの注文：** 種類をまぜる。いまは全部「おおもり」になっている。
  - 量を変える注文：例「シチュー すくなめ！」「あぶらあげ おおもり！」
  - 好物を断る注文：例「はちみつ いらない」
  - 両方をくみ合わせた注文
  - 注文があるときは、見た目より注文を優先して判定する。吹き出しはカウンターに来ているあいだずっと出す。
  - 2 重に描いているところ（おかわりの子の吹き出し）を直す。
- **3 めんのおかわり：** その面ですでに食べた子が、奥の席から立って列の 2 番目に割りこむ。種類はキツネに決め打ちしない。
  - 割りこむ動き（席から歩いてくる、列が 1 人ぶん下がる）を見せる。
  - おかわりもその面の人数（18 人）に数え、鍋の量の計算にも入れる。
- **動き：**
  - 子が列の右から歩いてくる。先頭の子が渡されたら、列が 1 人ずつ前へ進み、次の子がカウンターへ歩いてくる。待ち時間は、着いてから減らしはじめる。
  - 渡された子は、評価を頭の上に出しながら席へ歩き、座ると食べはじめる。
    - いまは、歩いていく先の席と、座る席がずれている。同じ席にする。
    - 席がいっぱいになったら、いちばん古い子が立って帰る。
- **がっかりのとき：** その子をしょんぼり（熱いものなら溶けかけ）にし、評価「がっかり」を出す。1 秒ほど見せてから、ゲームオーバーの画面にする。
- **鍋が空になったとき：** よそっているとちゅうで鍋が空になったら、その鍋の音とカタカタを止める。その子の分が足りないまま渡したら「鍋が足りなかった」でがっかり。
  - 判定は、ずれが ±30% を超えて、その鍋が空のとき。
- **さくらちゃんの分：**
  - 全員に配り終えたら、カウンターでさくらちゃんが自分の器によそって食べる場面にする（2〜3 秒）。
  - 画面の上に重ねて 2 匹目のさくらちゃんを描くのはやめる。いまは場面のさくらちゃんと重ねたさくらちゃんの 2 人が出ている。
  - 結果は「おなかいっぱい」「すくなくて しょんぼり」「空のお皿で しょんぼり」の 3 通り。
- **ポーズ画面：**
  - 「おと：ON／OFF」のボタンを、ふつうのボタンの形で出す。いまは「ポーズON」という文字になっている。
  - 「つづける」「タイトルへ」も置く（011 のポーズ画面にならう）。
  - ポーズ中に左上の「❚❚」を押したら、もどる。
- **タイトル画面：** design.html の ① のように、給食室の場面の上にタイトルを出す。各面の最高の ★ とハイスコアも出す。
- **面クリアの画面：** design.html の ⑨ のように、★、内訳（ぴったり・いいね・まあまあの人数と点数、おなかいっぱい、面クリア）、平均点、ごうけいを出す。さくらちゃんも描く。
- **ゲームオーバーの画面：** design.html の ⑩ のように、がっかりの理由をひとことで書く。

## 4. デモとエンディング（いまは文字だけ）

`demo.ts` に、場面として動くデモを作る。011 の `demo.ts` のように、時間で進む短い演出にする。タップで先へ進められる。

- **1 めんのあと：**
  1. 奥の席のみんなと、さくらちゃんが「いただきます！」。
  2. 食べ終えたクマが、お盆を持って、もう一度列に並びかける。
  3. さくらちゃんが気づいて「あしたね」。
- **2 めんのあと：**
  1. 黒板に「あしたは ゆきまつりの とくべつ きゅうしょく」のお知らせ。
  2. 列のうしろに、雪だるまがこっそり並んでいる。
  3. さくらちゃんが振り向くと、雪だるまは止まる（だるまさんがころんだ風）。
- **エンディング（3 めんのあと）：**
  1. 全員に配り終えたあと、雪だるまが「おかわり！」と、シチューの鍋を持ち上げて持っていこうとする。
  2. 熱くて溶けかける（`melt` が増えていく）。
  3. みんなで、かき氷を雪だるまにかけて助ける（かき氷のつぶが飛ぶ）。
  4. 元にもどった雪だるまも、みんなといっしょにかき氷を食べる。
  5. 「おしまい」。

## 6. ボット

- ボットは、子の答え（`wants`）を直接見てよい。そのかわり、人のまちがいをまねる。
- **腕前を分けるもの：**
  - 離すタイミングのずれ：秒で持ち、よそう速さを掛けて量のずれになるようにする。はちみつは同じずれでも量のずれが小さい。
  - 判断するまでの遅さ：子がカウンターに着いてから、最初に押すまでの時間。品ごとに次へ移るときにも、少し間をおく。
  - まちがえる割合：
    - ちがう品をよそう
    - おなかの音・注文を見落として、1 段階ちがう量にする
  - ちがう品をよそったときは、気づいて「こうかん」で直す。量を見落としたときは、気づかずに渡す。
- **「もりすぎ」ボット：** タイミングは「ふつう」と同じで、毎回ねらいより +10% 多くよそう。
- **`npm run bot` の表：** 腕前ごと・面ごとに次を出す。読みやすく桁をそろえる。
  - 到達率、クリア率、★ の分布、平均点、おなかいっぱいの割合
  - がっかりの理由の内訳（面ごと）
  - 鍋が足りなくなった回数

数値の調整（難しさ）は、こちらで `stages.ts` の値だけを変えて行います。ボットと表が、上のとおりに正しく動くところまでで止めてください。
