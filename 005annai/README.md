# さくらちゃんの案内係 ⛄

ゆきまつりの入口で、やってくるお客さんをスワイプで会場へ案内する仕分けゲーム。
昔のフラッシュゲーム「ウシは左へトラ右へ」の遊び方（ぎっしり並んだ列の先頭を左右に振り分ける）を、
シマエナガの「さくらちゃん」と冬の森の動物たちに置きかえたもの。まぎれこんでくる雪だるまは、変装を見やぶって入場お断りにする。

**TypeScript + Vite + Canvas2D** の完全クライアントサイド構成。キャラクターも背景も
画像ファイルを使わず、すべて Canvas2D のコードで描いている。

## 遊び方

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| 鳥を「そらの かいじょう」へ | `←` / `A` / 左へドラッグ | 左スワイプ |
| けものを「もりの かいじょう」へ | `→` / `D` / 右へドラッグ | 右スワイプ |
| 雪だるまを入場お断り | `↑` / `W` / 上へドラッグ | 上スワイプ |
| スタート・決定 | クリック / `Space` / `Enter` | タップ |
| ポーズ | `P` / `Esc` / 左上の「❚❚」 | 左上の「❚❚」 |
| 消音 | `M` | ポーズ画面の「おと：ON／OFF」 |

- お客さんは奥の門から受付までぎっしり並んで、少しずつ前へ進んでくる。よく見えるのは先頭だけで、うしろのお客さんは頭しか見えない。
- 先頭のお客さんを振り分ける。スワイプは指を離すのを待たずに、動かした瞬間に決まる（下スワイプは何もしない）。
- **まちがえた向きに案内するか、先頭が受付のロープまで来たら、その場でゲームオーバー**（コンティニューなし）。
- 1 人 10 点＋すばやさボーナス（最大 10 点。先頭がロープから遠いうちに案内するほど高い）。コンボはない。
- ハイスコアは端末に保存する（`localStorage`、ゲームオーバーのときも記録）。

## お客さん

| 向き | お客さん |
|---|---|
| ← 鳥 | カラス、ヤマガラ、ゴジュウカラ、アカゲラ、シマエナガ |
| → けもの | エゾリス、エゾモモンガ（飛ぶけれどけもの）、キタキツネ、ユキウサギ |
| ↑ 雪だるま | 変装なし、カラスのお面、リスの耳としっぽ、キツネのお面、ウサギの耳、炭で黒くぬる、どろで茶色くぬる、キツネの着ぐるみ、シマエナガのお面 |

どの変装でも「にんじんの鼻」「小枝の腕」「下の段の雪玉のまるい形」のどれかが必ず見える。

## 面

| 面 | 終わり方 | 来るお客さん | 雪だるま | 列の速さ（人／秒） |
|---|---|---|---|---|
| 1 | 40 秒 | カラス・エゾリス・シマエナガ | 変装なし | 0.5 → 0.75 |
| 2 | 45 秒 | ＋ヤマガラ・キタキツネ・ユキウサギ | お面・耳 | 0.7 → 0.95 |
| 3 | 50 人さばいたら | 全種類 | ぬり・着ぐるみ・シマエナガのお面が中心 | 0.9 → 1.2 |

- 1 面のあと「おきゃくさん いっぱい！」、2 面のあと「ゆきだるまの さくせんかいぎ」の休憩デモ。
- 3 面を終えたらエンディング「ゆきまつりは だいせいこう！」。

数値は `src/game/stages.ts` にまとめてある。自動プレイ（1 人ごとに一定の秒数で正しく振り分ける）で確かめた目安：
1 人 0.9 秒以内なら最後まで、1.2 秒だと 3 面の終盤、1.4 秒だと 2 面で間に合わなくなる。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173/
npm run build      # dist/ に出力（base: './' なのでサブパス配信でもそのまま動く）
```

- `design.html`（開発時だけ）：場面ごとの画面と、お客さん・変装ゆきだるまの一覧。
- 開発時はコンソールから `__game`（状態）、`__seededRandom`（乱数の固定）、`__render` を使える。
